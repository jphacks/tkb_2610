# ミケルナ 全身コマアニメーション

横歩行16枚、手前・奥への歩行各8枚、停止・方向転換・表情12枚の計44枚。
内蔵image_genで作成した全身画を使い、耳・尻尾・足を切り離して変形させない。
目のハイライトは付けない。正面・後ろの中間画を通して向きを変える。

`frames/` は足元の高さを合わせた透過PNG。元絵への加工は全体の上下位置調整、縮小、ほぼ不透明な画素のアルファ正規化のみ。
生成条件・採用元のハッシュは `manifest.json`、確認用一覧は `contact-sheet.jpg`。
元の高解像度画像は作業フォルダの「アニメーション検討/ミケルナ_アプリ用追加素材」に保管。

再生成: Pillowを使えるPythonで `python tool/prepare_mikeluna_sprites.py`。
配信用WebPとDartのコマID一覧を同時に更新する。各コマの間に透明な余白を取り、隣のコマが描画に混ざらないようにする。
アプリでは一枚の画像として一度だけ読み込み、各表示には独立した再生状態を持たせる。

停止・振り向きの制御は `lib/core/mikeluna_animation.dart`、表示は `lib/widgets/mikeluna_sprite_view.dart`。
部屋の移動は振り向き前に0.68秒待ち、移動速度に応じて歩行周期を変える。
他のキャラクターのRive素材や最終進化の表示は引き続き既存の方式を使う。

生成画の輪郭・接地のわずかな揺れはある。実画面での方向転換と停止を確認して改善する前提で管理する。
