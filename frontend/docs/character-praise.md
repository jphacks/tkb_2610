# キャラごとの褒め言葉を編集する

57キャラそれぞれに性格・一人称・話し方を設定しています。
ホームの雑談10種類とは別に、善行投稿後の褒め言葉に使う設定です。
性格は図鑑の見た目とホームのセリフをもとに用意した初期案なので、ここから自由に調整できます。

## 1. 性格と口調を変える

正本は `backend/src/config/character-personalities.json` です。
キャラ名（たとえば「ヒノレオ」）で検索し、そのブロックを編集します。

```json
"stage1_courage": {
  "name": "ヒノレオ",
  "personality": "挑戦する人を応援する熱血な子",
  "firstPerson": "おれ",
  "tone": "元気で勢いのあるため口。「やったな」「かっこいいぞ」。威圧しない",
  "demoTemplate": "{action}んだな！やったな、かっこいいぞ！"
}
```

| 項目 | 編集内容 |
|---|---|
| `stage1_courage` などのキー | 画像IDとの対応。変更しない |
| `name` | 図鑑と同じキャラ名。改名する場合は図鑑の定義も合わせる |
| `personality` | 何に気づき、どう喜ぶ性格か |
| `firstPerson` | 一人称。AIは必要な時だけ使う |
| `tone` | 文の勢い・丁寧さ・語尾。具体例を入れると伝わりやすい |
| `demoTemplate` | デモ用の褒め文。本番AIにも話し方の例として渡す |

`demoTemplate` の `{action}` は1つ残してください。
カテゴリごとに「人にやさしくできた」「感謝を伝えられた」などが入ります。
その後に「んだね」「のですね」などを続けると自然な文章になります。

本番では例文を固定表示するのではなく、投稿の具体的な内容を拾った文章をAIが作ります。
たとえば同じ「席をゆずった」という投稿でも、ヒノレオは元気にたたえ、
コハガメは落ち着いて認め、ミケルナはやさしい猫口調で褒める方針になります。

## 2. デモにも反映する

リポジトリの一番上のフォルダで、設定を編集したあとに実行します。

```sh
python3 tools/generate_character_personalities.py
```

`frontend/lib/data/character_personalities.dart` を自動生成します。
このDartファイルを直接編集せず、JSONを直してから再生成してください。
設定が同期しているかは次のコマンドで確認できます。

```sh
python3 tools/generate_character_personalities.py --check
```

デモは固定のカテゴリ文を性格別の文型に当てはめます。AIによる具体的な内容の生成は本番APIで行います。
デモのカテゴリ文を変える場所は `frontend/lib/data/character_praise.dart` の `demoPraiseActions` です。

## 3. 全体の褒め方を変える

`backend/src/lib/gemini.ts` の `buildDeedSystemInstruction` を編集します。
全キャラ共通の長さ（20〜50文字程度）、投稿内容を具体的に褒める方針などを指定しています。
語尾だけを後から置換せず、AIが文全体を性格に合う口調で組み立てます。

処理は次の順です。

1. `backend/src/services/deeds.service.ts` で投稿を予約する。
2. 予約で確定した個体IDと所有者から、画像IDを取得する。
3. 画像IDに対応する性格・口調をAIへ渡す。
4. AIの褒め言葉を、これまでどおり善行記録の `praise` に保存する。
5. 結果表示・育成記録は保存された文章をそのまま表示する。

進化する投稿では、行動を見ていた進化前の口調を使います。次の投稿から進化後の口調になります。
同じ投稿IDの再送では保存済みの文を返します。過去の記録は設定変更や進化で書き換わりません。
不明な画像IDはポノ、旧カメIDはコハガメに対応します。
無効な投稿の案内は中立な文で返すよう指示し、有効性判定・カテゴリ・XP・HPの計算は従来のままです。

## 4. 確認して反映する

```sh
# リポジトリの一番上で
npm run test:personality --prefix backend

# frontend フォルダで
flutter test test/character_praise_test.dart test/repository_test.dart test/flow_test.dart test/evolution_test.dart test/api_repository_test.dart test/character_speech_test.dart test/home_speech_test.dart
```

本番への反映にはバックエンドのビルド・再デプロイが必要です。
デモへの反映には上記の生成後、Flutterアプリを再起動・再ビルドします。
DB変更やSQL追加、APIリクエスト項目の追加は不要です。
AIの口調は生成結果によって揺れるため、本番の具体的な投稿でも確認・調整できます。
