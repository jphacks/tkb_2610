# ホーム画面のセリフを編集する

57キャラ × 10種類 = 570個を、アプリ内の固定データとして用意しています。
画像の図鑑と同じ57種（ポノ1種・第一進化7種・第二進化49種）です。
サーバーやデータベースの変更は不要です。

## セリフを変える場所

`frontend/lib/data/character_speech.dart` の `characterSpeechLines` を編集します。
キャラ名のコメントで検索して、その下の10行の文章を書き換えてください。

例：ポノのセリフは次のブロックです。

```dart
// ポノ
'base_01': [
  'おかえり、会いたかったよ',
  'えへへ、そばにいてね',
  // 以下、合計10個のセリフ
],
```

- `'base_01'` などのキーは画像と対応するIDです。変更しないでください。
- `'文章',` の形で、1キャラにつき10個を維持してください。
- 同じキャラ内で同じ文章を重複させないでください。
- 小さな吹き出しに収まるよう、短い一言にしてください。目安は20文字前後です。
- キャラ名・画像IDの対応自体は `frontend/lib/data/character_catalog.dart` にあります。

## いつ切り替わるか

1. ホームを開いた時、そのキャラの10個から1個をランダム表示します。
2. キャラをタップすると、直前の言葉以外の9個からランダム表示します。
3. 進化・世代交代でキャラが変わった時も、そのキャラの言葉を選び直します。

画面の再描画だけでは選び直しません。時間経過だけでの自動切替はありません。
タップ時の上下動は2秒で通常に戻りますが、選んだセリフはそのまま残ります。
抽選結果は保存せず、ホームを開き直すと再抽選します。
善行を投稿した後の結果メッセージは、これまでの結果表示のままです。

## ランダム表示や見た目を変える場所

- `frontend/lib/data/character_speech.dart` の `pickCharacterSpeech`：抽選方法。
- `frontend/lib/features/home.dart` の `_syncSpeech`：初回・進化・世代交代での更新。
- 同じファイルの `_onCharacterTap`：タップ時の更新と2秒の動き。
- `frontend/lib/widgets/speech_bubble.dart` の `ValueKey('character-speech')` 周辺：吹き出しの文字サイズ・最大行数。白く丸い、しっぽ付きの吹き出しです。`room_character.dart` で名前・キャラクターと一体で移動します。

編集後はアプリを再起動して確認してください。

## 確認用テスト

`frontend` フォルダで実行します。

```sh
flutter test test/character_speech_test.dart test/home_speech_test.dart test/widget_test.dart test/flow_test.dart
```

全57種に10個ずつあること、空白や重複がないこと、連続して同じ言葉が出ないこと、
ホームでの切替とタップ動作を確認します。
